# for baby 💜

Birthday site. Upload this folder to GitHub Pages and send her the link.

## Put it on GitHub (free link)

1. Go to [github.com/new](https://github.com/new)
2. Repository name: `birthday-baby` (or anything)
3. Public → Create repository
4. Click **uploading an existing file**
5. Drop every file from this folder:
   - `index.html`
   - `playlist.html`
   - `watch.html`
   - `songs.js`
   - `.nojekyll`
6. Commit
7. Repo → **Settings** → **Pages**
8. Branch: `main` → folder `/ (root)` → Save
9. After a minute the link is:

`https://YOUR-USERNAME.github.io/birthday-baby/`

Send her that.

## Pages

- **The card** — your wishes
- **BTS playlist** — click a song, it plays on the page (works on GitHub)
- **Tonight** — you both open this page: songs stay in sync, call is on the right (Jitsi). Watch2Gether is there too: [w2g.tv](https://w2g.tv)

On Tonight, whoever clicks a song, both of you hear it. Keep the page open on both phones/laptops.
